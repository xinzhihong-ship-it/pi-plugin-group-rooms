---
name: Group Rooms
description: Guide shared-room setup and collaboration through native PI-Desktop sessions.
---

Use the 群聊 / Group Rooms sidebar category to create or join a room in the MAIN content pane. Each computer chooses its own locally accessible project folder; mount a NAS before choosing its path. Hosting is receiving: creating a room (or an invitation) starts the incoming listener, and only the host ever listens; joining dials out and never binds. There is no separate listening switch, and leaving the last hosted room stops receiving.

Open a room row to enter its native session. Chat through the existing native composer with @member or @all. Use Members beside the composer to open the existing WorkPanel for approval, per-member model/thinking configuration, and recipient selection. Changing configuration or selection never runs an agent; native managed submit is the execution entry.

Do not create a separate transcript, message input, plugin side panel, or background prompt. Preserve host confirmations for worker operations. Do not invent invitations, member approval, connection status, or tool results. This integration targets pending host SDK additions at tentative >=0.18.0-beta.3; released stock 0.17 does not support it.
